# 工作台市场人工验收单

这是给开发者一次手工操作用的清单；填完后 Agent 复用，不默认再用 Computer Use 重做。

- 公开仓库/授权范围/许可证：
- 安装来源（源码 commit / Release URL / npm 精确版本）：
- 包名/版本/hash/实际 Profile：
- Desktop 版本、OS、架构：
- 执行者、日期、结果记录或截图位置：
- 自动包检查结果：

| 项目 | 通过/失败/未验证/不适用及理由 |
| --- | --- |
| 安装并打开正确版本，已安装列表及入口正常 | |
| 目录选择取消无副作用、确认后可用；路径失效能恢复 | |
| 当前工作台/项目/会话归属正确，多会话切换与重启恢复正确 | |
| 无会话时业务可用；主动请求 Agent 后只进入本工作台会话，保留草稿且不自动发送 | |
| 原生/工作台模式切换、侧栏展开/收起、窄面板、焦点和公共入口符合宿主规则 | |
| 核心任务从输入到结果可完成；错误能恢复；图标正常 | |
| 资料目录/会话指示器在适用分支有真实依据，不显示假绿灯 | |
| 最终版本真实截图、素材有权公开，包/截图不含凭据与私人资料 | |
| 官方开发规范第8节及市场规范第6节其它适用项已逐项覆盖 | |

确认语示例：“我在上述来源/版本/平台手工完成本表各适用项，结果如表；以下未验证项保留。”未验证项不能用一句全部通过掩盖。

Agent记录为“开发者确认”或“Agent实测”，不混写。仅失败、缺项或影响范围变化需要补验。参照 [市场发布流程](../docs/10-MARKET-PUBLISHING.md) 继续准备 YAML、远端 PR 与审核证据。
