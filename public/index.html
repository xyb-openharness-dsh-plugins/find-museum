地图与搜索

地图采用高德 Web 服务，经本机服务端代理加载；Key 不写入页面或安装包。当前 MCP 查询与地图服务分别验证。

第一次使用高德？

  1. 登录高德开放平台，在“应用管理 → 我的应用”创建一个应用。
  2. 添加 Key，服务平台选择“Web 服务”。本工作台使用本机服务代理，请不要选择“Web 端 JS API”。
  3. 按高德控制台要求完成认证、开通所需服务，并查看静态地图、地点搜索、地理编码及路径规划的配额。
  4. 复制 Key 到下方保存，再点击“检查连接”。Key 仅留在本机，过期或额度不足时可在这里更换。
