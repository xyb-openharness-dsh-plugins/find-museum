# 宋韵备用线描资源

8份原创透明SVG：瓦当、两款窗棂、园亭、回纹、流云、铺首、莲瓣碗意象。文化形制参考与建议尺寸见manifest.json。引用网页用于了解文化要素；没有把网页照片复制或转描为自有素材，不冒充精确文物测绘。自有路径采用MIT，参考网页保持原权利。

- 装饰背景宽180–420px，园亭可240–600px；窗棂160–320px；回纹240–640px。建议不透明度5–12%，不压正文。
- SVG有viewBox、透明背景、单一1.8线宽；内联后可用currentColor换色，img方式使用默认石绿。小于48px时改用简化功能图标，不强行缩小复杂纹样。
- 一个版面只选一种主纹样，页首/页尾二选一；铺首更适合章节收尾或档案入口，不做满屏底纹。莲瓣碗与苏州示例关联，其他城市主馆须重新核实代表器物。
- 不把这些要素一律标成宋代文物。它们属于跨时代中国文化形制，在宋韵留白系统内作为现代装饰使用。
