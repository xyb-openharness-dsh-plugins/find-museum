# 本机地图 403 修复记录

日期：2026-10-16。

## 原因与方案

OSM 公共瓦片返回包含 Access blocked 的 403 图片。仅更换点位数据不能解决底图拒绝访问。停止请求 OSM 瓦片，改用用户授权的高德 Web 服务静态地图；本机服务代理请求，Leaflet 保留交互能力。底图、点位统一 GCJ-02；保留图面署名。不是 JS SDK，不要求向前端暴露 Key。

## 验证

- 高德地理编码：status=1 / infocode=10000。
- 高德静态地图：HTTP 200，返回有效 PNG。
- 原型浏览器截图：苏州底图、5 个馆址、路线编号正常，403 图片消失。
- 自动测试：参数边界、图片类型、缓存、服务错误不泄漏 Key 通过；业务 14 项测试通过。
- 全项目文件扫描：未发现本机 Key；配置文件权限 0600。
- 该记录不宣称已安装、已加载到 DSH Desktop。

## 可复用经验

地图是独立的服务依赖，应分别检查数据、坐标系、底图请求与界面渲染。底图失败不应阻止馆单和路线编辑。不要通过轮换公共瓦片域名掩盖服务拒绝问题。配置值只保存在机器级私有目录；错误信息只显示经过筛选的错误码。拖动触发异步请求时使用代次标识，避免旧响应覆盖新视野。
