# 宋代风格外观 · 宋韵留白

## 可复用提示词

为博物馆文旅工作台设计宋韵外观。让人感到从容、清雅、愿意慢慢阅读；主基因是宋画一角留白和书卷排版，辅助为工笔器物线描。采用天青、浅绿、浅蓝与浅黄的低饱和配色，绢纸色打底，深青墨色承担正文对比。标题仿宋或宋体，正文16–18px、行高1.8–1.95；字号不为塞内容而缩小。线条纤细、柔和，以留白和淡墨分隔建立层次，少圆角、少阴影；不铺浓重色块，不堆卡片，不用蓝紫渐变。

先按任务分类，再对齐元素。页面入口等分或按容器重排；筛选栏每项有独立标签和足够输入宽度；主行动只有一个视觉焦点。空状态只出现一次并给下一步；技术状态放次级位置。首页先给目的地和选馆，再展示清单数量与去设计路书；旅行项目配置不抢主要任务。窄屏自动分行，禁止横挤或把中文压成竖条。

瓦当、花窗、园亭、回纹或铺首每页只选一种，作为边角5–12%淡色装饰，不能挡字；功能图标与装饰分开。仿宋缺字时回退Songti SC/系统衬线，不从外网强制加载字体。重要交互、焦点与错误仍保持清晰，不为素雅牺牲可读性。

## 实现参数

| 要素 | 参数 |
| --- | --- |
| 绢色背景 | #f5f3e9；内容留白#faf9f3 |
| 深青墨字 | #2f4947；次级#5d716d |
| 石绿强调 | #648f82；选中浅绿#e4eee6 |
| 天青/浅蓝 | #e5edf0；细线#d1dcd5 |
| 浅黄辅助 | #f0edda；只用于待办/来源提示 |
| 字体 | FangSong/仿宋/STFangsong/Songti SC/serif |
| 分区 | 节间28–40px，行间16–24px；细线1px |
| 控件 | 最小44px；focus 2px深青边线；选中含文字/aria，不只靠颜色 |
| 宽度 | 业务容器内响应；档案筛选3列→2列→1列；导航5列→3+2→选择器 |

用户指定的多种浅色作为辅助面，正文始终由深色保证对比。宋代审美是现代设计借鉴，不把汉瓦当/明清园林/铺首等跨时代要素误称为宋代实物。

## 模板与切换

- 宋韵：public/song.css，body[data-theme=song]，默认启用。
- 经典：public/app.css，外观切换选经典即可；共享修复后的业务逻辑和数据，不加载旧版本bug代码。
- 原0.2.0外观存档：design/themes/classic-v0.2.0.css及HTML；历史快照不是另一份需同步维护的业务实现。
- 选择仅保存在当前Desktop来源localStorage，不切数据目录、不重建旅行或原生会话。
- 备用SVG：assets/song，元数据/参考/尺寸/许可齐备。SVG为原创意象，自动照片转线稿仍是后续增强。

## taste决策与验收

主：宋韵留白（马远/夏圭的一角构图）；辅：工笔器物线描。单句自检：内容像一卷能随手翻阅的旅行札记，文化气质来自字、线和气口，而非纹样堆叠。

须验证900/700/480/360px业务容器与大字模式、筛选可读和空状态、经典切换、右侧原生Agent完整保留。尚未取得截图时不能写成视觉验收通过。

## 四季淡彩花木（0.2.3替代上一版）

用户否定手绘SVG四君子方案，改用图像生成透明PNG。春兰夏竹秋菊冬梅，宋徽宗花鸟画工笔气韵、细腻淡彩、浅浮雕般的体积关系；避免图标化、粗线和重色。工具为内置image_gen，具体模型未暴露，不能标为已确认gpt-image-2。

素材置于assets/song/paintings，提示词见PAINTING-PROMPTS.md。只保留图像本体alpha，网页控制淡化。首屏标题区右下角呈现，宽屏215×225/38%，窄屏130×170/28%；不再在页面底部追加空白，也不遮住标题和按钮。经典外观和打印隐藏。
