# 寻馆 0.2.0 · 预发布

- 五个入口调整为发现博物馆、设计路书、我的收藏、路书档案、数据配置；增加清晰的下一步入口和折叠配置。
- 加入清单为切换操作：再次点击移除，支持未选择旅行时暂存；清单不预设参观时间。
- 收藏支持博物馆、美食、景点、Citywalk，以及想去/去过和笔记；标签检索最多5个高德候选，勾选后保存，保留原收藏状态。
- 博物馆保留4–8小时深度参观规则，其他地点独立设置；迁移前备份，旧旅行不清空。
- 路书冻结版本、可读浏览、恢复设计、指定版本发Agent、附件回顾，以及HTML/MD/CSV/JSON下载和分享摘要。
- MIT许可证；保存完整市场投稿提示词与官方规范。全国历史名录仍为5535条2019快照，动态状态须出发前核实；高德Key由使用者自配，不随包公开。
