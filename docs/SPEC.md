# 寻馆工作台规格 v0.1.0

## 目标与核心流程

为博物馆爱好者发现目的地大馆与周边100km特色县域馆。交付DSH Desktop工作台、可复用任务技能、可追溯全国CSV和SQLite轻量业务系统。

1. **搜索和建清单**：本地5535条历史名录检索、高德POI、单选/多选/全选；只记录想去的馆，不要求时长、日期或Day N。输入只形成用户本次旅行清单，不冒充官方名录认证。
2. **编排**：在弹窗拖拽、上下移动、分配Day 1–30；4小时基本参观，6或8小时深度参观，不提供1–2小时打卡。显示每日参观合计，不包括交通、用餐，不强制具体出发时刻。先在草稿中调整，确认才写数据库。
3. **交付**：保存规划JSON或导出MD/CSV/HTML；将当前冻结清单/路线和任务要求追加到唯一原生Agent草稿，用户发送后共同完善路书。未编排清单也可请Agent提出安排建议，但导出路线须先完成编排。

## 数据与证据

CSV是官方2019历史基线，5,535唯一ID、32分组含兵团，未知字段留空；不称为最新全国目录。内存SQLite提供只读目录索引，首次保存前不写业务目录。独立用户SQLite保存旅行/清单/站点/收藏/候选/结果，用户确认的补充不会被名录更新覆盖。

城市/县域名称推断只是候选；馆址按实际来源核实。GCJ-02点位和高德底图一致，100km仅直线半径。常规时间不证明当日开放，非unknown状态须来源、核实时间与有效区间；失效后提示待核实。馆藏不保证在展，公众号不能访问不编摘要。

第一步清单与第二步站点分表，新增页面不跟随改表。增量迁移1–4、revision锁、批量事务及可重建快照见SCHEMA.md。Agent回流当前采用完整馆址候选，不伪称已实现字段级Claim表或读取全部聊天。

## Desktop与工具

真实repository派生身份，不复制旧工作台ID。左业务65%可折叠，右宿主唯一原生会话，不覆盖公共导航/设置。新旅行在用户选择目录后落盘，再ensureSession；开场白只追加草稿。打开已有旅行不自动建会话。显式session→trip映射优先，前台、owner、当前项目、iframe源/窗口和异步ticket均需检查。

高德Web服务通过本机后端提供地理编码、POI、详情、驾车和静态地图。Key在机器级私有配置，前端不回显，Git/包不携带。配置页提供官方申请链接。静态地图停止操作后更新，不能宣称等同JS SDK。

Agent只调用当前原生会话实际可用搜索/地图技能，agent-reach等为可选渠道。任务指南复制到旅行input并进入提示词；放进包不等于注册了工具。无联网工具时保留未知和本地能力。

## 验收与发布

按业务单元成组回归，再构建/真实tgz检查/解包运行/目标安装/实际界面验收。官方规范2026-10-16复核，与仓库快照一致。仓库身份、页面版本、tag和附件版本统一；记录安装包哈希，Key扫描不得输出Key。

用户已授权开发、测试、发布和Git管理。GitHub Release与市场收录是独立路径；没有Desktop真实运行截图不自动投稿市场。正在运行的宿主不由Agent自行重启。未实测部分如实保留，不把契约测试当宿主UI验收。

持续增强范围：新年度名录、全量地址和公众号补齐、临时公告、公交时刻、预约余量、自动时间窗、字段证据历史、PDF渲染和可选记忆。这些不以模拟数据冒充已完成。
