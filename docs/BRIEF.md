# 寻馆：需求确认

状态：业务目标明确，项目名、仓库身份与视觉方案待开发者确认。

用户：博物馆爱好者，尤其希望在目的地城市的大馆之外发现100km范围内有特色的县域馆、专题馆与非国有馆。
核心流程：选择城市/中心点/参观日期/交通方式 → 地图与规则筛选 → 查看馆及来源、核实开放条件 → 加入路线并调整顺序/分日 → 导出或追加到原生 Agent 草稿 → 用户发送后继续补充路书 → 保存与回顾。

已确认：全国4000+馆基础名录CSV；地图；等级/城市/详细地址/坐标/特色展品/官网和公众号介绍/开放时间/开放状态字段；100km县域发现；路线可排序、导出、交给DSH；左业务65%可折叠、右唯一原生会话；会话管理按给定选址适配原则。

补充建议：区分机构与馆址；参观入口而非停车场坐标；直线距离与路程分开；字段级来源和日期；时段冲突和预约检查；未核实不等于开放；开放公告有生效区间；县级与小众是不同维度；保留无等级馆，不以评级代替特色判断。

授权：本地初始化、设计、数据获取、实现与检查。未授权公开发布、市场投稿或自动预约/购票。UI与真实仓库身份待确认，暂不安装骨架。
